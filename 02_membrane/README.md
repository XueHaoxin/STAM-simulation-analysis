# Membrane-only analysis

This folder contains a script for analyzing membrane-only simulations, corresponding to Extended Data Fig. 6d in the manuscript.

Bilayer thickness and area per lipid (APL) were calculated using LiPyphilic. Six membrane systems with different lipid compositions and Ca<sup>2+</sup> concentrations were simulated, with three independent replicates per system.

For LiPyphilic installation instructions, see the [LiPyphilic installation guide](https://lipyphilic.readthedocs.io/en/latest/installation.html).
